# Análise do APK

Pacote identificado: `com.emergency.app`

Componentes/telas identificados pelos recursos e classes:
- `MainActivity`
- `RegisterUserActivity`
- `RegisterContactsActivity`
- `SettingsActivity`
- `SosWidget`

Elementos identificados:
- botão `btnSOS` / `btnWidgetSOS`
- cadastro de usuário
- cadastro de contatos
- contador de contatos
- configurações
- temas `Theme_SOSEmergencia`, `Theme_SOSEmergencia_Dark` e `Theme_SOSEmergencia_Daltonism`
- reconhecimento de voz
- localização
- confirmação `Enviar SOS?`
- ação `ENVIAR AGORA`
- limite de 5 contatos

A implementação web é uma adaptação visual/funcional de front-end. Não copia o código Android e não executa chamadas reais de emergência, SMS, voz ou localização.
